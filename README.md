# 📊 Dashboard KPI Empresarial — Gratis

Herramienta visual para medir y controlar los indicadores clave 
de tu negocio en un solo lugar. Diseñada para dueños de empresa, 
gerentes y equipos que necesitan tomar decisiones basadas en datos reales.

---

## ✅ ¿Qué incluye esta versión gratuita?

- Panel de control con los 8 KPI más importantes de cualquier negocio
- Indicadores de ventas, finanzas y operaciones
- Semáforo automático (verde, amarillo, rojo) según tu meta
- Vista mensual de rendimiento
- Fácil de usar — sin conocimientos técnicos

---

## 📊 KPIs incluidos

| Indicador | Qué mide |
|-----------|----------|
| 💰 Ingresos totales | Dinero que entra al negocio |
| 📉 Gastos totales | Dinero que sale del negocio |
| 📈 Margen de ganancia | % de utilidad real |
| 🛒 Número de ventas | Cantidad de transacciones |
| 👥 Clientes nuevos | Nuevos clientes del mes |
| 🔄 Tasa de conversión | % de prospectos que compran |
| ⭐ Satisfacción cliente | Nota promedio de clientes |
| 🎯 Cumplimiento de meta | % de avance hacia tu objetivo |

## 🚀 ¿Cómo usarlo?

1. Descarga el archivo `dashboard-kpi-basico.xlsx`
2. Abre con Excel o Google Sheets
3. Ingresa tus metas mensuales en la columna de objetivos
4. Ingresa tus resultados reales cada mes
5. El semáforo se actualiza automáticamente
